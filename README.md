## 项目简介

**Light-Searching-for-Terminus** 是一款极简操作的 1K（单键）节奏游戏。整个游戏画面只有一条光线与若干面板：

- 光线沿谱面预设的路径匀速前进；
- 遇到 **反射板（Reflector）** 时，玩家需要在判定窗口内按键，光线才会按预设角度反射，继续沿下一段路径行进；
- 遇到 **透射板（Transmitter）** 时，按键仅参与判定，光线保持方向继续前进，不改变光路。

玩家用同一个按键完成所有操作，操作门槛低，但对节奏精准度与路径预读能力要求较高。

## 核心玩法

### 光线

- 光线沿谱面定义的**路径**匀速移动，速度由谱面（或 BPM / 流速参数）决定。
- 路径由一系列节点构成，相邻节点之间为直线段；反射板放置在节点（或线段上的指定位置）上。
- 光线在反射板处按预设的**出射角度**转向。

### 反射板（Reflector）

- 光线抵达反射板时，若玩家在判定窗口内按下按键，判定成功，光线完成反射并继续前进。
- 若按键过早、过晚或未按键，判定为 **Miss**，光线在反射板处中断，并以 Miss 特效熄灭该段光线，随后从下一段路径起点恢复。
- 反射板是**主判定物**，决定曲目的主要节奏骨架。

### 透射板（Transmitter）

- 光线抵达透射板时，玩家同样需要按键进行判定，但**光线方向不变**，直接穿透并继续前进。
- 透射板用于制造**连续按键与变奏节奏**，不改变光路，视觉上呈现为光线短暂闪光穿过。
- 透射板的判定逻辑与反射板一致，同样遵循统一判定窗口。

### 判定与距离

- 每个判定物在光路上都有一个**判定中心点**；
- 光线距离判定中心点进入「一定距离」区间内时按下按键，即视为有效输入并进入判定；
- 剩余输入（过早、过晚、无输入）全部计为 **Miss**。

## 判定系统

### 判定窗口

| 判定 | 时间窗口 | 说明 |
| :--- | :--- | :--- |
| **Perfect** | ±50 ms | 最小判定窗口，精准命中 |
| **Good** | ±100 ms | 次一级判定（可配置） |
| **Miss** | 超出窗口 / 无输入 | 判定失败，光路中断 |

> 最小时间判定为 **Perfect ±50 ms**；窗口大小可在设置中调节（见[配置项](#配置项)）。

### 判定规则

1. 光线进入判定区间后，接收玩家输入；
2. 输入时间与判定中心点的时间差 `Δt` 落入对应窗口即判定成功；
3. 每个判定物**仅接收一次有效输入**，重复按键会被忽略；
4. 未在窗口内输入 → **Miss**；
5. 反射板判定失败时光线中断；透射板判定失败时光线继续前进但计入 Miss。

### 连击与准确率

- 连击（Combo）：连续判定成功累加，Miss 时清零；
- 准确率（Accuracy）：按各判定权重加权平均计算；
- 分数：根据具体的miss good perfect数量，算出总分，满分为1000万分
- 评级：根据准确率与 Miss 数量给出 P / S / A / B / C / D 等级。
  - P：ALL PERFECT 满分
  - S: >=985万
  - A：>=960万
  - B：>=920万
  - C：>=850万
  - D：< 850万

## 谱面编辑器

内置可视化谱面编辑器，用于制作与调试谱面。

### 功能

- **光线路径制作**
  - 在画布上自由添加 / 拖拽 / 删除路径节点；
  - 支持直线段与折线路径，节点吸附与角度约束；
  - 实时预览光线行进与反射效果。

- **判定物放置**
  - 在路径上放置反射板 / 透射板；
  - 设置反射角度、判定类型、判定偏移微调；
  - 支持批量复制、对齐与删除。

- **特效编辑**
  - 为判定物绑定命中特效（闪光、粒子、波纹、屏幕震动等）；
  - 设置特效触发时机与持续时间；
  - 特效参数实时预览。

- **歌曲与谱面对齐**
  - 导入音频并显示波形；
  - BPM 网格与节拍线显示，支持变速段落；
  - 音频偏移（Offset）校准，逐段对齐光路与音乐；
  - 时间轴缩放 / 拖拽定位。

- **路径修改**
  - 支持路径节点增删改、整体平移与旋转；
  - 修改后自动重算路径长度与判定时间点；
  - 撤销 / 重做（Undo / Redo）。

### 谱面文件

- 谱面以结构化文本格式存储（路径节点 + 判定物 + 特效 + 音频元信息）；
- 支持导入 / 导出，便于版本管理与分享。

```jsonc
{
  "meta": { "title": "...", "artist": "...", "bpm": 160, "offset": 0 },
  "path": [ { "x": 0, "y": 0 }, { "x": 100, "y": 0 } ],
  "notes": [
    { "type": "reflector", "time": 1200, "angle": 90, "effect": "flash" },
    { "type": "transmitter", "time": 1800, "effect": "ripple" }
  ]
}
```

> 字段以实际实现为准。

## 配置项

| 配置 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `perfectWindow` | 50 ms | Perfect 判定窗口 |
| `goodWindow` | 100 ms | Good 判定窗口 |
| `inputOffset` | 0 ms | 玩家输入延迟补偿 |
| `chartOffset` | 0 ms | 谱面音频偏移 |
| `lightSpeed` | 由谱面决定 | 光线行进速度 |
| `autoPlay` | false | 自动演示模式 |
